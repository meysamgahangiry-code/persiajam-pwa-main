بسته PWA نسخه اصلی صندوق پرشیا جام

- آیکون‌ها از لوگوی رسمی تعبیه‌شده در فایل HTML نسخه V10 استخراج شده‌اند.
- با اجرای آیکون نصب‌شده، صفحه واسط فقط برای لحظه‌ای پیام «در حال ورود» را نشان می‌دهد و سپس مستقیماً به صفحه لاگین MAIN هدایت می‌کند.
- هیچ فرم ورود، رمز عبور، داده مالی یا اطلاعات اعضا در این بسته وجود ندارد.
- این بسته فقط برای انتشار روی GitHub Pages است.
- فایل‌ها را از حالت ZIP خارج کنید و محتویات را در ریشه مخزن جدید MAIN قرار دهید.
- مخزن و آدرس MAIN را از مخزن و آدرس TEST جدا نگه دارید.
